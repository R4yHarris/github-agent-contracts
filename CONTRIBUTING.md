# Contributing

This project welcomes issues and pull requests to **this repository only**.

## Before you start

1. Read `AGENTS.md` and `docs/DAY1_SCOPE.md`.
2. Keep changes scoped. Split unrelated work.
3. Do not commit secrets.

## Tests

```bash
node --test tests/*.test.mjs
```

## Commit messages

Human bootstrap commits are fine as normal conventional commits (`feat:`, `fix:`, `docs:`).

If an **agent** authors a commit, add trailers from `docs/commit-trailers.md`.

## CLA

Contributions to *this* repo are under MIT via inbound=outbound.

If you later send patches to `github/gh-aw`, `github/github-mcp-server`, or `microsoft/*`, follow that project’s guide and sign the Microsoft CLA on your personal GitHub account when the bot asks.
